# Manufacturing Data

This directory records the manufacturing-related outputs generated from the PCB design for academic documentation and design traceability.

## Board definition

- **Board size:** 51.75 mm × 31.00 mm
- **PCB:** 2 copper layers
- **Nominal thickness:** 1.6 mm
- **Board outline:** Rounded rectangular profile
- **CAD:** KiCad 9.x

## Included data

The `hardware/fabrication/gerbers/` directory contains the generated design-output files, including:

- Front copper
- Back copper
- Front solder mask
- Back solder mask
- Front silkscreen
- Back silkscreen
- Front paste
- Back paste
- Edge cuts
- NC drill data
- Top and bottom component-position files
- Gerber job metadata

These files are retained as part of the academic design record. Their presence does not imply that the board has been fabricated, assembled, or production-qualified.
