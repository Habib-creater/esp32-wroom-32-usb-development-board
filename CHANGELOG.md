- Added ESP32-WROOM-32 schematic.
- Added 2-layer PCB layout.
- Added USB-to-UART programming interface.

- Added USB and I²C ESD protection.
- Added GPIO expansion headers.
- Added BOM with manufacturer part numbers.
- Added Gerber, drill, and position outputs.
- Added schematic, architecture, pinout, manufacturing, and validation documentation.
